# HoverGifCard

Pokémon cards that swap a still sprite for an animated GIF on hover, and slide a
description panel up over the card on click.

<img width="2298" height="614" alt="Screenshot 2026-09-22 at 8 46 54 AM" src="https://github.com/user-attachments/assets/62be7865-9840-48be-8ab0-ff6ae6ebe0d2" />

Open `index.html` in a browser — no build, no dependencies.

- `index.html` — three cards (Gastly, Haunter, Gengar)
- `style.css` — layout, hover swap, slide-up back panel (uses native CSS nesting)
- `script.js` — toggles `data-active` on the back panel
